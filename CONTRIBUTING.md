# Guía de Contribución

¡Gracias por tu interés en contribuir a este proyecto de documentación de Infraestructura de Red y Seguridad Ofensiva!

Para mantener el orden y la calidad del documento, por favor sigue estas pautas.

## 📁 Gestión de Imágenes

Si tu contribución incluye nuevas imágenes (diagramas de red, capturas de pantalla de Kali Linux, configuraciones, etc.):

1.  **Ubicación**: Todas las imágenes deben guardarse estrictamente en el directorio:
    `assets/images`
2.  **Formato**: Preferiblemente utiliza formatos `.png` o `.jpg` para capturas y diagramas.
3.  **Nombres de archivo**: Usa nombres descriptivos en minúsculas, separados por guiones bajos (ej. `ataque_dos_resultado.png`, `topologia_vlan.png`).

## ✍️ Contribuciones a la Documentación

Toda la documentación se encuentra en archivos `.tex` dentro del directorio `pages/`.

### Proceso de Pull Request (PR)

1.  **Fork y Rama**: Crea un fork del repositorio y trabaja en una nueva rama para tus cambios.
2.  **Edición**: Realiza tus modificaciones en los archivos TeX correspondientes.
3.  **Descripción del PR**:
    - Al enviar tu Pull Request, **indica claramente qué cambios has realizado**.
    - Menciona si has añadido nuevas secciones, corregido errores ortográficos o actualizado diagramas.
    - Si es posible, adjunta una captura de cómo se ve el PDF compilado con tus cambios (opcional pero recomendado).

## 🐛 Reporte de Errores

Si encuentras algún error en la documentación técnica o en la compilación LaTeX, por favor abre un *Issue* describiendo el problema.
