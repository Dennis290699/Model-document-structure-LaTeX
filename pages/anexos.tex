\section{Anexos}

En esta sección se incluyen los recursos complementarios utilizados durante el desarrollo del laboratorio, tales como archivos de configuración, código fuente empleado en la construcción del entorno Hadoop, capturas de pantalla del proceso de despliegue y ejecución del clúster, así como una guía rápida de comandos utilizados para la administración del sistema distribuido. 

Todos estos elementos se encuentran organizados y documentados en el repositorio oficial de GitHub creado por el autor del presente informe. Dicho repositorio reúne la evidencia completa del proceso experimental y constituye un apoyo integral para la comprensión detallada de la metodología aplicada.

\subsection{Repositorio del Proyecto}

El repositorio correspondiente al laboratorio se encuentra disponible en el siguiente enlace:

\begin{center}
\texttt{https://github.com/Dennis290699/Hadoop-Taller\_Practico\_N1}
\end{center}

\subsection{Contenido del Repositorio}

El repositorio contiene, entre otros, los siguientes elementos:

\begin{itemize}
    \item \textbf{Código fuente del entorno Hadoop:} Archivos necesarios para la construcción de la imagen Docker personalizada, incluyendo el \texttt{Dockerfile}, archivos de configuración de HDFS, YARN y MapReduce, así como los scripts auxiliares utilizados durante la práctica.
    
    \item \textbf{Archivo \texttt{docker-compose.yml}:} Documento central para el levantamiento del clúster Hadoop en contenedores Docker, configurado para gestionar servicios como \textit{NameNode}, \textit{DataNode}, \textit{ResourceManager} y \textit{NodeManager}.
    
    \item \textbf{Capturas de pantalla:} Imágenes que documentan cada uno de los pasos del procedimiento, incluyendo la construcción de la imagen, levantamiento de contenedores, ejecución de comandos internos, pruebas en HDFS y resultados del trabajo MapReduce.
    
    \item \textbf{Guía rápida de comandos:} Documento complementario que recopila los comandos clave utilizados para la gestión del sistema distribuido, tanto en Docker como en Hadoop, facilitando su reproducción en futuros entornos.
\end{itemize}
